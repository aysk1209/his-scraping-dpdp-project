Four Techniques, Seven Rules

The same four extraction tasks, the same seven DPDP Act 2023 rules, the same source. The compliance score alone puts a public AI agent within a few hundredths of the rule-driven technique. Two more axes — which fields it took and whether it took the same ones twice — separate them.
