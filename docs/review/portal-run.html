The portal run

A real browser logs into a hospital portal it has never been told about, works out what is where, and every technique scrapes it. every page load recorded

We wrote this portal — and built it as a system we do not control. The scraper holds a username and a password and nothing else: no API, no data attributes, no hooks. If it can read the portal, it is because it does what it would do against a real one.
